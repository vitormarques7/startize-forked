# 🚀 Startize Pomodoro

Timer Pomodoro inteligente focado em microtarefas para aumentar sua produtividade.

**Disponível como aplicação web E extensão de navegador!**

## ✨ Recursos Principais

- ⏱️ **Sistema Pomodoro Completo** com pré-foco, foco, pausas curtas e longas
- 🎯 **Microtarefas** - Comece com 5 minutos de aquecimento
- 🌓 **Modo Escuro** - Tema claro e escuro
- 🎵 **Sons de Fundo** - Ruído branco, chuva, oceano, água ou YouTube
- 🏆 **Sistema de XP/Níveis** - Acompanhe seu progresso
- ⚙️ **3 Predefinições** - Salve suas configurações favoritas
- 🔔 **Sons de Notificação** - Alertas ao completar cada fase
- 💾 **Armazenamento Local** - Tudo salvo no seu navegador

## 📦 Instalação

### Como Extensão de Navegador (Recomendado)

```bash
npm install
npm run build:extension
```
